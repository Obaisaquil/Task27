# My Card Gallery

A responsive React card gallery featuring 18 colorful containers with a sticky navigation bar and API loading/error handling.

## Features
- Sticky navbar with Photos sticker.
- 18 colorful cards displaying 600 × 600.
- Responsive grid layout.
- Centered loading indicator.
- Error message when the internet connection fails.
- Black background with colorful containers.

## Technologies Used
- React.js
- CSS3
- JavaScript
- Fetch API

## Run Locally

```bash
npm install
npm run dev
```

## Error Handling

Displays `Loading...` while fetching data and `Error: failed to fetch` if the API request fails.
